# Python GitHub Project 🎯

A collection of small Python projects I built for fun and learning.  
This repository includes games, utilities, and experimental scripts exploring different aspects of Python programming.

---

## 📂 Project Structure

The repo contains independent Python scripts and some assets.  
Each script can be run individually — no central application.

### Example Projects

- **Games**
  - `number_guessing_game.py` – A simple guessing game against the computer.
  - `tic_tac_toe.py` – Classic tic-tac-toe game.
  - `snake_game.py` – Basic snake arcade game.

- **Utilities**
  - `password_generator.py` – Random password generator.
  - `qr_code_generator.py` – Creates a QR code for a given input.
  - `weather_report.py` – Fetches and shows weather information.
  - `to_do_list.py` – Simple task manager.
  - `pollution_checker.py` – Checks AQI levels.

- **Other Experiments**
  - `average_cricket.py` – Calculate batting average from cricket scores.
  - `daily_journal.txt` – Sample output file from one of the scripts.
  - **`jarvis/` – Virtual Assistant**
    - Early attempt at building a **Jarvis-like AI assistant**.
    - Uses an **LLM API** (Large Language Model) for answering queries.
    - Includes basic **Windows control features** (e.g., opening apps, system tasks).
    - A personal experiment in combining Python scripting with AI-powered interaction.

> Note: Some filenames may currently contain spaces or typos — they will be gradually cleaned to standard Python naming (`snake_case`).
